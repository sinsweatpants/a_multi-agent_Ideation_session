توثيق مشروع: نظام تطوير القصص متعدد الوكلاء
مقدمة
هذا المشروع عبارة عن تطبيق ويب متكامل يهدف إلى تطوير الأفكار القصصية باستخدام نظام متعدد الوكلاء (Agents)، حيث يتعاون 11 وكيلاً متخصصاً في مجالات السرد، بناء الشخصيات، التوتر، الحوار، العالم، وغيرها، لتوليد أفكار قصصية متكاملة وتحليلها ومراجعتها بشكل جماعي.

الهيكل العام للمشروع
agents: مجلد يحوي ملفات تعريف وكلاء الذكاء الاصطناعي، كل ملف يمثل وكيل متخصص (مثل تطوير الشخصيات، التوسع، التوتر، الحوار، النوع الأدبي، الواقعية، بناء العالم، إلخ).
public: واجهة المستخدم (HTML, CSS, JS) لعرض النظام والتفاعل معه.
.env: إعدادات البيئة (مثل رقم المنفذ).
.gitignore: تجاهل ملفات البيئة والمكتبات.
orchestrator.js: المنسق الرئيسي الذي يدير سير العمل بين الوكلاء.
package.json و package-lock.json: إدارة الحزم والاعتمادات.
server.js: خادم Express.js الذي يخدم الواجهة ويوفر نقطة API رئيسية.
شرح وكلاء النظام (Agents)
كل وكيل عبارة عن ملف JS يحوي:

اسم الوكيل ووظيفته الأساسية.
دليل إرشادي مفصل حول مسؤولياته، أدواته، معايير الجودة، ونماذج إخراج العمل.
أمثلة على كيفية التعاون مع الوكلاء الآخرين.
أمثلة:

characterDevelopment.js: بناء شخصيات عميقة ومتطورة نفسياً.
conflictTension.js: توليد وتصعيد التوتر والصراعات الدرامية.
dialogueVoice.js: صياغة الحوارات المميزة لكل شخصية.
genreTone.js: ضبط النوع الأدبي والنبرة العامة للقصة.
storyArchitect.js: بناء الهيكل السردي العام للقصة.
...إلخ.
كل وكيل يحتوي على نماذج جاهزة لتوليد ملفات تعريف الشخصيات، خرائط العلاقات، تحليل التوتر، إلخ.

سير العمل البرمجي
واجهة المستخدم:

إدخال مفتاح API الخاص بـ Gemini.
إدخال موجز الفكرة الإبداعية.
عرض النتائج (الأفكار، مراجعات الوكلاء، النقاش، القرار النهائي).
الخادم (server.js):

يستقبل الطلبات من الواجهة.
يمررها إلى المنسق الرئيسي (orchestrator.js).
المنسق الرئيسي (orchestrator.js):

ينادي وكلاء Gemini عبر API.
يطلب من كل وكيل توليد فكرة أو مراجعة أو نقاش.
يجمع النتائج ويعيدها للواجهة.
الوكلاء (agents/...):

كل وكيل يملك دليل إرشادي ونماذج إخراج.
يتم استدعاؤهم حسب الحاجة من المنسق.
التقنيات المستخدمة
Node.js و Express.js: لبناء الخادم وتقديم API.
Axios: للتواصل مع واجهة Gemini API.
HTML/CSS/JS (Tailwind): لبناء واجهة المستخدم.
Dotenv: لإدارة متغيرات البيئة.
هيكل CommonJS: لتنظيم الوحدات البرمجية.

دليل النبرة (Tone Bible)
تحليل الوظائف (Function Audit)

خاتمة
